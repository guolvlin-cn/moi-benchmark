# Enron 50题×3轮端到端复现SOP

本文是从 Git 数据建立数据库、运行产品并重新计算三轮指标的正式入口。只想运行一轮50题时，使用[一轮50题运行SOP](一轮50题运行SOP.md)。

## 1. 复现范围

每个产品提交同一组50题三次，共150次独立请求：

- 模型固定为 `qwen3.7-plus-2026-05-26`；
- 每次请求使用独立会话，不继承上一题上下文；
- Chat2DB和Wren连接同一份MySQL `enron_eval_v1`；
- MOI使用同源CSV导入MatrixOne知识库，并保存原生执行结果；
- 产品正常返回空SQL、执行失败或超时属于真实结果，不得静默覆盖；
- 采集器中断后可以用同一 `run-id` 续跑缺失记录。

## 2. 安装与数据校验

在 `enron_eval_SOP/` 目录执行：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp config/database.env.example .env
# 修改.env中的本机MySQL连接信息
source .env
.venv/bin/python scripts/verify_csv_files.py
```

如果本机尚未建立数据库：

```bash
.venv/bin/python scripts/setup_mysql.py
```

如果同名数据库已经存在，脚本默认停止以保护数据。只读确认数据库与冻结快照一致：

```bash
.venv/bin/python scripts/verify_mysql_snapshot.py
```

只有确认需要删除并重建同名数据库时，才可以使用 `scripts/setup_mysql.py --rebuild`。

## 3. 产品准备

三个产品的连接、模型、Docker网络和知识库准备方式见[一轮50题运行SOP](一轮50题运行SOP.md)第3至5节。三轮复现沿用完全相同的产品配置。

复制产品环境变量模板，并只在本机填写：

```bash
cp config/products.env.example .products.env
source .products.env
```

不要提交 `.env`、`.products.env`、Wren私有配置、API Key、产品密码或登录信息。

## 5. 正式运行

确认Dry Run展开的模型、问题文件和输出目录正确后，删除命令末尾的 `--dry-run` 正式运行。

运行结果写入：

```text
runs/<product>/<run-id>/
├── run.json
├── predictions.jsonl
├── validation.json
└── run_summary.json          # 由支持的采集器生成
```

MOI还会在本地生成较大的 `raw/` 事件目录。`runs/`和原始事件默认不进入Git；确认需要冻结的新基线时，应另行审核、脱敏和生成校验值。

## 6. 续跑规则

- Chat2DB和Wren使用同一条命令、同一 `run-id` 再次运行，会跳过已经记录的题号与轮次；
- MOI恢复服务后，在原命令中增加 `--resume`；
- 产品返回的正常失败记录不自动重试；
- 只有采集器故障、错误问题文本或上下文污染可以纠正，并且必须保留审计证据。

## 7. 独立验证150条产物

```bash
.venv/bin/python scripts/validate_three_rounds.py \
  --product chat2db \
  --run-dir runs/chat2db/chat2db_qwen37_3x

.venv/bin/python scripts/validate_three_rounds.py \

  --run-dir runs/wren/wren_qwen37_3x \

```

只有 `validation.json` 中 `validation` 为 `passed`，结果才可以进入评分。

## 8. 计算Golden指标

评分前再次加载MySQL连接环境：

```bash
source .env
```

Chat2DB和Wren的生成SQL与Golden SQL在同一MySQL快照执行：

```bash
.venv/bin/python scripts/score_three_rounds.py \
  --product chat2db \
  --run-dir runs/chat2db/chat2db_qwen37_3x

.venv/bin/python scripts/score_three_rounds.py \
  --product wren \
  --run-dir runs/wren/wren_qwen37_3x
```

MOI使用保存的MatrixOne原生结果与MySQL Golden结果比较：

```bash
.venv/bin/python scripts/score_three_rounds.py \
  --product moi \
  --variant baseline_no_semantic \
  --run-dir runs/moi/moi_qwen37_no_semantic_3x
```

评分生成 `evaluation.json`，核心指标包括：

- Execution Accuracy：正确请求数/150；
- SQL Success Rate：成功执行SQL数/150；
- Repeat Correct Rate：同一题三轮全部正确的题数/50；
- End-to-end Latency：平均值、P50、P95；
- Token Usage：仅统计产品真实提供的Token，缺失时保持为空。

## 9. 参考结果回归验证

仓库自带的四组冻结结果不需要重新调用产品即可校验：

```bash
.venv/bin/python verify_frozen_results.py
```

该命令检查四组结果均为50题×3轮、核心指标与冻结清单一致，并验证数据、Schema、语义配置、评分代码和参考结果的SHA256。
