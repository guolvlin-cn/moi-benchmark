# Enron评测SOP目录与文件说明

## 运行时阅读顺序

1. `README.md`：确认评测范围、冻结结果和入口；
2. `data/README.md`：理解六个CSV及其指纹；
3. `docs/三轮150次复现SOP.md`：从建库到评分完整执行；
4. `reference_results/README.md`：理解仓库自带的参考结果；
5. `provenance/SOURCE_MAP.md`：追溯参考结果来源和审计记录。

## 目录职责

| 路径 | 内容 | 是否可由新运行覆盖 |
|---|---|---|
| `benchmark/` | 50题、详细口径、Golden SQL和case元数据 | 否 |
| `data/raw/` | 六个规范CSV | 否 |
| `data/manifest.json` | CSV大小、SHA256、行数、NULL和内容指纹 | 否 |
| `database/schema/` | 带表注释和字段注释的MySQL建库语句 | 否 |
| `config/` | 不含真实凭据的环境与产品配置模板 | 可以新增模板，不能写真实密钥 |
| `runners/` | Chat2DB、Wren、MOI底层采集器 | 代码可演进，正式运行需记录版本 |
| `scripts/` | 建库、验证、一轮/三轮统一入口和评分包装器 | 代码可演进 |
| `scoring_code/` | 产生冻结基线的核心评分实现 | 冻结基线不可修改；新口径应新建版本 |
| `semantic/` | MOI语义配置v2 | 现有版本冻结；新配置应使用新文件名 |
| `reference_results/` | 四组统一模型只读参考结果 | 否 |
| `reviews/` | 人工审核附加标注 | 不能覆盖自动结果 |
| `provenance/` | 来源映射、冻结清单和SHA256 | 冻结文件不可修改 |
| `.agents/skills/` | 随项目分发的Codex运行Skill | 可按SOP演进 |
| `runs/` | 新运行的本地产物，Git默认忽略 | 是，只能写自己的新run-id |

## 统一入口脚本

| 文件 | 用途 |
|---|---|
| `scripts/verify_csv_files.py` | 不连接数据库，验证六个CSV |
| `scripts/setup_mysql.py` | 安全建立和导入MySQL `enron_eval` |
| `scripts/verify_mysql_snapshot.py` | 只读验证数据、NULL、Schema和注释 |
| `scripts/run_one_round.py` | 运行一个产品的一轮50题 |
| `scripts/validate_one_round.py` | 验证一轮50条采集产物 |
| `scripts/run_three_rounds.py` | 运行一个产品的50题×3轮 |
| `scripts/validate_three_rounds.py` | 验证三轮150条采集产物 |
| `scripts/score_three_rounds.py` | 计算三轮Golden指标 |
| `verify_frozen_results.py` | 验证仓库自带四组参考结果和SHA256 |

## 本地文件与Git文件

以下文件只存在于复现者本机，已被 `.gitignore` 排除：

- `.venv/`；
- `.env`、`.products.env`；
- `runs/`；
- MOI/Wren原始大日志、Cookie、会话凭证和容器数据。

以下文件应随Git分发：

- 六个规范CSV；
- Schema、问题、Golden SQL和语义配置；
- 采集、验证和评分代码；
- 脱敏配置模板；
- 冻结结构化参考结果和来源校验文件。
