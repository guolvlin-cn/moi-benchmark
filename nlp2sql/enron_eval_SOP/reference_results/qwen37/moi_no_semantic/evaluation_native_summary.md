## 判定说明

- Golden SQL 在 MySQL 8 执行；MOI 使用对话过程中实际保存的 MatrixOne 原生执行结果，不把 MOI SQL重新放到 MySQL 执行。
- Golden 含 `ORDER BY` 时进行有序比较，否则进行无序比较。
- 列数、行数和规范化后的值必须一致；额外返回未要求的列也判为不一致。
- MOI 一题执行多条 SQL 时，只比较最终答案引用的结果集；任一被引用结果与 Golden 完全一致即可通过。
- 对分页结果按相同列结构合并后再比较，避免把 `e03` 的 1000+91 行分页误判为失败。

## 跨引擎排序提示

`e10`、`h02`、`h07` 的三轮结果均与 Golden 具有相同的无序行集合，SQL 也包含对应排序，但 MySQL 与 MatrixOne 的默认字符串排序规则不同，导致严格有序比较失败。正式主分仍按统一严格口径记为失败；如采用“忽略数据库默认 Collation 差异”的辅助口径，这 9 次可单独标注为引擎排序等价，不应与 SQL 逻辑错误混为一类。
