# Enron 50题字段覆盖表

新版题集覆盖6张表的全部32个字段。这里的“覆盖”指题目要求在筛选、连接、分组、排序、计算或结果输出中实际使用该字段。

## enron_email

| 字段 | 主要覆盖题目 | 考察方式 |
|---|---|---|
| id | e02、e06、m01、m19 | 邮件去重计数与跨表连接 |
| people | e14、e15、m01、m09、h04、h07、h10 | 归档员工目录筛选、分组和分区排名 |
| mailbox | e06、e07、e10、e16、m01、m09、m16、m19、h10 | 精确文件夹筛选、聚合和每人Top 1 |
| nnn | e20 | 原始邮件序号排序，不把它误解为数量 |

## enron_emailinfo

| 字段 | 主要覆盖题目 | 考察方式 |
|---|---|---|
| id | e02、e03及多数跨表题 | 当前邮件逻辑主键和去重计数 |
| messageid | e03 | 空主题邮件结果输出 |
| date | e11、e12、m08、m18、h05 | 文本日期解析、年月日筛选和排序 |
| subject | e03、e04、e17、m10、m17、h03 | 空值、关键词、回复识别和主题标准化 |
| from | e01、e05、e18、m02、m03、m05、h01、h02等 | 发件地址规范化、聚合和集合运算 |
| to | m14 | 当前邮件To汇总文本预览，并与明细数量对照 |
| xfrom | e19 | 当前邮件原始发件人显示值聚合 |
| xto | m14 | 当前邮件X-To汇总文本预览，并与明细数量对照 |
| body | e08、m03 | 正文关键词筛选 |

## enron_emailorig

| 字段 | 主要覆盖题目 | 考察方式 |
|---|---|---|
| id | m10、m17、h09 | 将正文中的历史邮件头关联到当前外层邮件 |
| nth | m10、m17、h09 | nth=1上一层邮件头筛选和邮件链深度统计 |
| subject | m17 | 输出引用历史邮件的主题 |
| from | m10、m17 | 统计或输出引用历史邮件的发件人 |
| to | m17 | 输出引用历史邮件的收件人头值 |
| xfrom | e13、m17 | 历史X-From字段完整性检查和输出 |
| xto | e13、m17 | 历史X-To字段完整性检查和输出 |

注意：当前数据中 `enron_emailorig.xfrom` 和 `enron_emailorig.xto` 全部为空。e13故意将其设计为数据完整性题，预期结果为两个0；这仍然能够测试模型是否选对“历史邮件头”表，而不是误用当前邮件的同名字段。

## 覆盖类型总结

- 单表字段读取：e03、e09、e10、e13。
- 两表关联：e20、m02、m09、m13、m17、m19。
- 三表及以上关联：m05、m14、h04、h07、h08。
- 数据质量与表示差异：e03、e13、m14。
- 文本与模糊语义：e04、e08、e17、h03。
- 日期解析：e11、e12、m08、m18、h05。
- 集合、反连接和交集：h01、h02、h07、h08。
- 序号字段：e20、m11、m17、h09。
- 窗口排名：h04、h10。
