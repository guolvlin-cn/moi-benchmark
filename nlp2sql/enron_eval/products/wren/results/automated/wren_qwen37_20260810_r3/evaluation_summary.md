# Wren Qwen3.7 三轮评测结果

## 评测配置

- 产品：本地部署 WrenAI
- 模型：`qwen3.7-plus-2026-05-26`
- 数据库：MySQL `enron_eval`
- 语义配置：未额外配置业务语义
- 题目：50 题，每题独立生成 3 次，共 150 次
- 正确性口径：Wren SQL 与 Golden SQL 均在同一 MySQL 数据库执行，比较最终结果；SQL 文本不要求相同

Repeat Correct Rate 判断三次执行结果是否都与 Golden 一致，不要求三次 SQL 文本完全相同。12 道稳定正确题中，6 道题的三次 SQL 文本并不完全相同，但执行结果都正确。

## 主要失败结构

- 47 次没有生成 SQL：45 次为生成等待超时，2 次为 Wren 判断 schema 中没有“回复邮件”字段而拒绝生成。
- 4 次生成了 SQL 但未成功执行：`h01` 三轮均缺少派生表别名；`m14` 第 1 轮被只读安全检查判定为不允许的语句。
- 47 次 SQL 可以执行但结果错误：常见表现为多返回或少返回列、行数不符、过滤条件和排序结果不符。

由于 Wren SQL 和 Golden SQL 都在 MySQL 中执行，本次不存在 MOI 评测里的 MySQL/MatrixOne 默认排序规则差异，不需要提供引擎差异修正分数。
