# 人工语义审核

本目录保存严格自动评测之后的附加人工审核信息，不覆盖产品原始预测或自动评分结果。

## 审核范围

- 页面只列出至少有一轮被自动判错的“产品 × 题目”组合。
- 同一道题的三轮结果并排展示。
- 自动正确的轮次仅作上下文，不要求重复标注。
- 自动判错轮次标注为：完全正确（1分）、部分正确（0.5分）或错误（0分）。

## 启动

在 `nlp2sql/enron_eval` 目录运行：

```bash
.venv/bin/python scripts/review/human_review_server.py
```

然后打开 `http://127.0.0.1:8765`。

标注会自动保存到 `annotations.json`。`baseline_manifest.json` 记录人工审核前原始运行文件及其校验值。
