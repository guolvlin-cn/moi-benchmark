# Qwen3.7 三产品自动评测统一对比

## 统一口径

- 模型：`qwen3.7-plus-2026-05-26`
- 数据集：Enron私有评测集50题
- 运行次数：每题3次，共150次
- 本报告只使用自动评分，不使用任何人工审核修正
- Execution Accuracy：执行结果与Golden结果严格匹配的次数 / 150
- SQL Success Rate：生成非空、安全且成功执行SQL的次数 / 150
- Repeat Correct Rate：同一题3次结果均与Golden一致的题数 / 50
- Chat2DB与Wren在统一MySQL快照执行候选SQL；MOI使用MatrixOne原生执行结果与MySQL Golden结果比较

## 结论

1. 不做人工审核时，MOI有语义配置的自动准确率最高，为66.00%。
2. MOI加入语义配置后，相比无语义配置增加14次正确结果，Execution Accuracy提高9.33个百分点；三轮稳定正确题增加3题，Repeat Correct Rate提高6个百分点。
3. MOI无语义配置仍比Chat2DB高5.34个百分点；MOI有语义配置比Chat2DB高14.67个百分点。
4. Chat2DB的SQL成功率最高且稳定，但严格语义准确率为51.33%，说明“SQL能运行”不等于“答案正确”。
5. Wren第二次运行减少了未生成SQL，但准确率仍为32.67%，主要问题不只是网络，还包括语义理解和SQL逻辑。
