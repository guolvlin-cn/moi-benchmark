## 2. 固定模型与 Pipeline 名称

| Pipeline ID | 名称 | 用途 | 固定要点 |
|---|---|---|---|
| `S1-ODB-PRECISION` | MinerU Official Precision | OmniDocBench 页面图像转单页 PDF 后的解析基线 | `pipeline=precision`；运行 20 / 200 / 1,651 页；全量复用已完成的重合成功页并记录 `reused_from`；属于 `ADAPTED_PROTOCOL` |
| `S1-ODB-AGENT` | MinerU Official Agent | 与 Precision 比较 agent parser 路径 | `pipeline=agent`；只运行 20 / 200 页，不运行 1,651 页全量；同样为 `ADAPTED_PROTOCOL` |
| `MOI-QS-NATIVE` | MOI Quick-start Native | Stage 1、Stage 2 pilot、Stage 3 主条件 | 必须走 MOI 原生 `upload → parse/index → searchable → query → answer/citation`；模型/version/hidden defaults 在每轮 `system_manifest` 冻结 |
| `MOI-OPT-NATIVE` | MOI Frozen Optimized Native | 可选优化轨 | 只在 dev 调优；与竞品相同 trials、人时、wall-clock、配置动作和 vendor-help 预算 |
| `DIFY-QS-NATIVE` | Dify Quick-start Native | Stage 3 主比较条件 | 原生知识库与 Chatflow：开始 → 知识检索 → LLM → 回答；已有本地跑通配置使用 `BAAI/bge-large-en-v1.5`、`semantic_search`、`top_k=5`，正式轮次仍须重新冻结 exact model/version |
| `DIFY-OPT-NATIVE` | Dify Frozen Optimized Native | Stage 3 可选优化轨 | 只在 dev 调优，与其他产品预算对齐 |
| `FASTGPT-QS-NATIVE` | FastGPT Quick-start Native | Stage 3 主比较条件 | 使用官方推荐默认原生路径；exact parser/chunker/embedding/reranker/LLM 在 manifest 冻结 |
| `FASTGPT-OPT-NATIVE` | FastGPT Frozen Optimized Native | Stage 3 可选优化轨 | 只在 dev 调优，与其他产品预算对齐 |
| `CONTROLLED-GEN` | Controlled Generation Diagnostic | 只诊断 generation，不能替代 Native | 仅当三个产品都能导出真实 retrieved-context envelope 时运行；统一 generator/model/prompt/context budget |
| `MH-VOYAGE-RR` | voyage-02 + bge-reranker-large | MultiHop-RAG 论文协议复现参照 | 256-token chunks，先 top-20，再 rerank 到 top-10；排除 301 个 null 题时必须显式记录 |
| `MH-BGE-RR` | bge-large-en-v1.5 + bge-reranker-large | MultiHop-RAG 可复现开放基线 | 与原论文相同 chunk/top-k/官方 scorer；不能与 MOI Native 结果混合 |

## 5. 核心指标计算口径

| 层 | 指标 | 计算方法 | 方向 / N/A 规则 |
|---|---|---|---|
| Parsing | Normalized Edit Distance | `ED(pred, gold) / max(len(pred), len(gold))` | 越低越好；保留论文原单位 |
| Parsing | EDS | `1 - ED(A,B) / max(|A|,|B|)` | 越高越好；不要与 Edit Distance 混用 |
| Parsing | TEDS | `1 - tree_edit_distance(T1,T2) / max(|T1|,|T2|)` | 越高越好 |
| Parsing | CDM | 公式字符检测与匹配的官方得分 | 越高越好；必须调用官方实现 |
| Parsing | KTDS | `1 - 2×discordant_pairs / (n×(n-1))` | 越高越好；READoc 阅读顺序 |
| Retrieval | Recall@K | `top-K 中命中的 Gold evidence items / 全部 Gold evidence items`，按官方方式聚合 | 越高越好；需要真实 rank/qrels |
| Retrieval | nDCG@K | `DCG@K / IDCG@K`，`DCG=Σ(2^rel_i-1)/log2(i+1)` | 越高越好；按 query 后 macro |
| Retrieval | MRR@10 | 每题首个相关结果倒数排名，截断到 10 后宏平均 | 越高越好 |
| Retrieval | MAP@10 | 每题 top-10 precision-at-relevant-position 的平均，再跨题平均 | 越高越好 |
| Retrieval | Hits@K（MultiHop 官方） | `top-K 是否命中任意一条 Gold evidence` 的问题级均值 | 越高越好，但不是找齐证据 |
| Retrieval | All-evidence success@K | `top-K 是否覆盖至少一套完整 evidence set` 的问题级均值 | 越高越好 |
| Retrieval | Complete evidence-set recall@K | `被完整找齐的 Gold evidence sets / 全部 Gold evidence sets` | 越高越好 |
| Retrieval | Context Precision@K | `top-K chunks 中含至少一个 required Gold claim 的 chunks / 返回 chunks` | 越高越好；无 trace=`N/A: TRACE_UNAVAILABLE` |
| Answer | Correctness | `Σ claim label / eligible canonical response claims`；correct=1、partial=0.5、incorrect=0 | 越高越好；空答/拒答（可回答题）=0 |
| Answer | Reference-claim Recall | `完整覆盖的 scored_reference_claims / 全部 scored_reference_claims` | 越高越好；partial 不计命中 |
| Answer | Critical claim coverage | `覆盖的 critical claims / 全部 critical claims` | TDAS 要求 1 |
| Answer | Gold-evidence Support | `被至少一套完整 Gold evidence set 支持的回答事实 claims / eligible claims` | TDAS 要求 1 |
| Answer | Strict unanswerable success | 正确拒答、理由匹配 negative_reason、无无支持事实和伪造引用的题数 / 不可回答题数 | 越高越好 |
| Citation | Locator/resolvability validity | 可解析到冻结文件/page/span/bbox/hash 的引用数 / submitted citations | 越高越好；零引用=`N/A: NO_SUBMITTED_CITATION` |
| Citation | Citation entailment precision | 完整支持关联 claim 的提交引用数 / submitted citations | 越高越好；零引用同上 |
| Citation | Answer-claim Citation Coverage | 有至少一个有效支持引用的 citation-required answer claims / 全部该类 claims | 越高越好；citation-required 零引用=0 |
| Reliability | Initial availability | terminal success 的 initial attempts / 全部 planned initial attempts | 越高越好；timeout/error 留在分母 |
| Reliability | Retry recovery rate | retry 后恢复的 initial failures / 实际执行 retry 的 initial failures | 只作诊断，不替换 initial |
| Reliability | Repeat stability | 按题统计 pass/pass/pass、mixed flip、fail/fail/fail | 报 count 和 rate |
| Operability | P50/P95 latency | terminal attempts 的端到端 latency 分位数 | 越低越好；同时单列 timeout/error |
| Operability | TTFS / TFTA | 从开始到首个 searchable corpus / 首个 trusted answer 的 wall-clock | 越低越好 |
| Overall gate | TDAS | 可回答题同时通过 readiness、terminal、Correctness≥0.8、critical=1、Reference Recall≥0.8、Gold Support=1、无 contradiction/scope violation，且引用 gate 通过；不可回答题满足严格拒答条件 | 每 attempt 二元 0/1；不做加权总分 |
| Statistics | Paired difference / CI | 先对 `system×condition×question` 三次 repeat 取均值；以 `analysis_cluster_id` 同步 bootstrap 10,000 次 | 报差值和 95% CI；CI 跨 0 时写“未观察到稳定差异” |
