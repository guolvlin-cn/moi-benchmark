## 2. 自然数 ----整数的子集（非负子集）

自然数 $\mathbf{N}$：0，1，2，…

  注意 自然数包括正整数和 0,最小的自然数为 0.

考试方法：

  (1) $z_1(+,-,x)z_2 = z$.
                  (2) $a,b \in \mathbb{Z}$，且 $\frac{b}{a} = z$：
- $b$ 是 $a$ 的倍数 ($b=ak$)
- $a$ 是 $b$ 的因数（可整除）
      例： $\frac{b}{4} = z \Rightarrow b = 4k (k \in \mathbb{Z})$.
            $$b = \dots - 8, - 4, 0, 4, 8, \dots$$
        例1：

$\frac{3}{a} = z(a + z) \\) a = 1, 3, -1, -3 $

$\frac{4}{a} = (2 + (a + z)) \\) a = 1, 2, 4.$
              $$\frac{4}{a} = z ^ {-} (a (- z) \Rightarrow a = - 1, - 2, - 4.$$
