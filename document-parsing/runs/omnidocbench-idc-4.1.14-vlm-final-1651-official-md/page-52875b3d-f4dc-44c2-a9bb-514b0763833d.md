#### 1.2.1.4【待定系数类型】

▲适用题型：

知道可以配凑出 $\left(\frac{m}{a} +\frac{n}{b}\right)\left(pa + qb\right)$ 结构，但是不能直接观察出系数的不等式题型；如：已知正实数 $x$、$y$ 满足 $\frac{1}{x + 3y} +\frac{1}{2x + y} = 1$，则 $x + y$ 的最小值为____.
▲方法原理：

1. 如果可以直接看出或者简单尝试可知系数关系的，则直接处理

比如：$x > 0, y > 0, x + 2y = 1$，则 $\frac{1}{4x + 3} + \frac{1}{2y + 1}$ 的最小值为______.
  变形：

$\n\left\{\n\begin{array}{l}\nx + 2y = \frac{1}{4} (4x + 3) + (2y + 1) - \frac{7}{4} = 1 \Rightarrow (4x + 3) + 4(2y + 5) = 11 \\\n\frac{1}{4x + 3} + \frac{1}{2y + 5} = \frac{1}{11}\bigg(\frac{1}{4x + 3} + \frac{1}{2y + 5}\bigg)[(4x + 3) + 4(2y + 5)] \\\n\text{此时建议结合换元处理结构更简单} \left\{ \begin{array}{l} 4x + 3 = m \\ 2y + 1 = n \end{array} \right.\n\end{array}\n\right.\n$
2. 不易看出系数关系的，则待定系数处理：

比如：$x > 0, y > 0, 3x + y = 1$，则 $\frac{1}{5x + y} + \frac{1}{5x + 3y}$ 的最小值为______.
  变形：

$3x + y = m(5x + y) + n(5x + 3y) \Rightarrow \left\{ \begin{array}{l}5m + 5n = 3\\ m + 3n = 1 \end{array} \right. \Rightarrow \left\{ \begin{array}{l}m = \frac{2}{5}\\ n = \frac{1}{5} \end{array} \right.$

$\Rightarrow \frac{1}{5x + y} + \frac{1}{5x + 3y} = \left(\frac{1}{5x + y} + \frac{1}{5x + 3y}\right)\left[\frac{2}{5}(5x + y) + \frac{1}{5}(5x + 3y)\right]$

此时建议结合换元处理结构更简单 $\left\{ \begin{array}{l}5x + y = m\\ 5x + 3y = n \end{array} \right.$
例题1.（全国·高三专题练习）已知正数 $x$, $y$ 满足 $\frac{2}{x + 3y} + \frac{1}{3x + y} = 1$，则 $x + y$ 的最小值（ ）
A. $\frac{3 + 2\sqrt{2}}{4}$
B. $\frac{3 + \sqrt{2}}{4}$
C. $\frac{3 + 2\sqrt{2}}{8}$
    D. $\frac{3 + \sqrt{2}}{8}$
例题2.（全国·高三专题练习）已知正实数 $x$, $y$ 满足 $4x+3y=4$，则 $\frac{1}{2x+1} + \frac{1}{3y+2}$ 的最小值为（）

  $\mathrm{c}. \frac{1}{2} + \frac{\sqrt{2}}{4}$
A. $\frac{3}{8} + \frac{\sqrt{2}}{4}$
B. $\frac{1}{2} + \frac{\sqrt{2}}{3}$
D. $\frac{1}{2} + \frac{\sqrt{2}}{2}$
