# Memoria 重复与近重复记忆处理正式数据集 v1

## 一、用途

该数据集用于验证 Memoria 单条记忆写入路径对重复和近重复内容的实际处理能力，正式范围收敛为三类：

1. 完全相同或只有首尾空格差异的文本能否复用原记忆；
2. 文本不同但人类判断语义等价时，能否在阈值内建立版本替换，并客观呈现阈值外漏检；
3. 独立事实和不同作用域的记忆能否正确并存。

本数据集不再将事实值变化视为 Memoria 的自动更新能力，也不再把连续版本链设为独立大类。连续链只作为第二类的加强子场景。

## 三、分类

| 分类 | 数量 | 主要目的 |
|---|---:|---|
| `exact_duplicate_reuse` | 10 | 验证完全相同文本及首尾空格差异的复用行为 |
| `semantic_equivalent_handling` | 24 | 验证语义等价文本在阈值内外的版本替换表现 |
| `coexistence_scope_isolation` | 16 | 验证独立事实及不同主体、类型、分支、用户正确并存 |
| **合计** | **50** | |

## 四、精确重复复用

共 10 个 case：

| 子类 | 数量 |
|---|---:|
| 完全相同文本 | 6 |
| 只有前导空格 | 1 |
| 只有尾随空格 | 1 |
| 首尾各一个空格 | 1 |
| 首尾多个空格 | 1 |

全部 case 的用户语义预期都是 `reuse`。空格样本被明确保留，用于验证当前“先生成 Embedding、再进入候选后比较 trim 文本”的处理顺序是否造成漏判。

## 五、语义等价记忆处理

共 24 个 case，所有文本对均由人判断为含义相同，不包含事实值变化：

| 子类 | 数量 | 筛选条件 | 用途 |
|---|---:|---|---|
| `single_inside_threshold` | 8 | 实测 L2 `<= 0.3162` | 验证产品设计范围内的单次版本替换 |
| `single_near_outside_threshold` | 8 | 余弦约 0.90～0.95，L2 略高于或高于阈值 | 客观呈现明显等价表达的阈值漏检 |
| `single_clear_outside_threshold` | 4 | 余弦 `< 0.90` | 呈现改写幅度较大时的能力边界 |
| `continuous_inside_threshold_chain` | 4 | 三个版本的两个相邻关系均在阈值内 | 验证 `A → B → C`、history 和活动版本完整性 |

第二类的用户语义预期统一为 `supersede`。阈值外 case 不是预期系统按照当前机制替换，而是用于计算“人类语义等价记忆替换率”，如实体现能力局限。

### 5.1 候选筛选

候选文本使用当前正式配置预先测距：

- Embedding：`text-embedding-v4`；
- 维度：1024；
- 请求格式：与 Memoria 源码一致，只发送 `model + input`；
- 阈值：L2 `0.3162`，约对应归一化向量余弦相似度 0.95。

每个第二类 relation 在 `selection_measurement` 中冻结筛选时的余弦相似度和 L2 距离。正式 runner 必须重新测量并记录实际值；如果正式值与筛选值发生漂移，不允许修改人工语义标签或静默替换 case。

## 六、并存与作用域隔离

共 16 个 case：

| 子类 | 数量 |
|---|---:|
| 同一作用域中的独立事实 | 8 |
| 不同 `subject_id` 的相同文本 | 2 |
| 不同 `memory_type` 的相同文本 | 2 |
| 不同 branch 的相同文本 | 2 |
| 不同 user 的相同文本 | 2 |

该类用户语义预期统一为 `coexist`。作用域隔离 case 使用完全相同文本，使向量距离为 0，从而证明并存来自作用域隔离，而不是相似度不足。

## 七、正式指标

报告以三类准确率为主：

1. 精确重复复用准确率；
2. 语义等价记忆替换率；
3. 并存与作用域隔离准确率。

第二类还需要分层报告：

- 阈值内单次替换准确率；
- 阈值附近但阈值外的语义替换率；
- 明显阈值外的语义替换率；
- 连续阈值内版本链完整率。

辅助指标包括当前阈值机制一致率、错误替换率、`superseded_by` 正确率、history 完整率、活动状态正确率和检索可见性一致率。

## 八、能力边界

该数据集不验证：

- 事实值变化的自动识别与更新；
- 自然语言矛盾检测；
- `/observe` 的大模型抽取质量；
- 批量写入；
- 人工 `correct`；
- 分支 Diff、Merge 或冲突解决；
- 阈值调优。
